Throughline

Privacy

Last updated: 6 September 2026

Throughline is a free, local-first library of runnable notebooks. This page describes what the product does — and does not — do with your data.

No account

Throughline does not require an account. We do not run a Throughline user database of notebooks, prompts, or API keys.

What stays on your device

  • API keys — stored in the browser (web) or the operating system keychain (desktop). They are never sent to Throughline servers.
  • Notebooks and run transcripts — kept in browser storage or, on desktop, in a folder you control on disk.
  • Marks and edits — stored locally with your library.

Network requests

When you run a notebook against a model provider, your device talks directly to the endpoint you chose (for example OpenAI, Anthropic, Google, Groq, OpenRouter, a company gateway, or a local server). Throughline does not proxy those requests. The privacy practices of each provider apply to that traffic.

The website may load optional on-device model assets from public CDNs (for example Hugging Face or jsDelivr) when you choose a downloaded model. Desktop builds use the same idea: traffic goes to destinations you configure, not to a Throughline backend for inference.

Hosting and analytics

The static website may be served via ordinary web hosting or a CDN. If a host enables basic access logs or a privacy-preserving analytics beacon (for example Cloudflare), those systems may see standard request metadata such as IP address and user agent. Throughline does not use that data to identify you, build a profile, or sell advertising.

Children

Throughline is a general productivity tool. It is not directed at children under 13, and we do not knowingly collect personal information from children.

Changes

If this policy changes in a material way, we will update the date above. Continued use of Throughline after an update means you accept the revised policy.
